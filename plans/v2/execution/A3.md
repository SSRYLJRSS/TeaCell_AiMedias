# A3：Pi 与完整助手交互

本文件为静态任务卡。先读 [执行总入口](../11-execution-guide.md) 与 [任务索引](README.md)。每次只读并执行分配的一个 ID；代码范围均相对于仓库根。新增名称在 [12](../12-implementation-contracts.md) 明确为拟建。所有卡同批包含必要定向测试/权威文档，门禁和交接执行 [14](../14-review-and-handoff.md)，未列出不代表可以省略。

## A3-01

**接入生产 Pi Host 与受控宿主协议**

- 前置：A2-05、A0-02。
- 需求索引：R02、R03、R54，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：需设计复核。
- 必读：A0-02 结论、03；src-tauri/src/utils/process.rs、src-tauri/src/lib.rs、src-tauri/tauri.conf.json。
- 允许范围：拟建 packages/agent-host/、Rust agent_runtime、构建资产声明及相应测试；使用已锁版本。

1. 把通过原型的 Host 引入正式构建，限定资源/会话目录和环境，使用应用拥有的进程与握手。
2. 实现请求/事件framing、精确版本握手、消息限制、实例/run ID、取消和03 §2.1的用户触发恢复；stdout只承载协议。验证退出期间不重启、同目录双开不产生第二写者。
3. 在开发/打包路径测试无全局 Node、Host 异常和旧实例迟到事件；只声明实际支持平台。
4. 使用A0已批准的版本组合与资源预算回归实际打包制品；差异/超限按09 §6处理，不能临时换最新版或放宽预算。

**验收与交付：** 无用户全局 Pi 配置也可工作；Rust 对 Host 帧执行精确字段、类型、引用和错误类别校验，命令拒绝能以固定分类诊断且不泄露原始文本；ACK 与请求的 command、conversationId/runId 一致，否则按结果未知处理；旧事件不能污染新 run；数据根规范化后必须仍是应用数据目录的直接子目录，且数据根/会话目录拒绝链接并固定目录身份后再写入。SDK 的会话发现必须使用固定目录快照；只对名称以目标 `conversationId` 结尾的 `.jsonl` 候选，在读取头部前由 Rust no-follow 打开并固定文件身份，且拒绝重解析点和多重硬链接；其他会话文件不能用目标 ID 请求 pin。新增会话也须先独占创建头部再固定，SDK 只能接收已 pin 的直接普通文件；关闭会话按 conversationId 释放其文件句柄。退出回收 owned 进程，无第二业务 DB。

**停下条件：** 原型与生产打包路径不同且未经验证，或真实凭据泄入环境时阻断。

## A3-02

**接入模型网关、Agent 用途和治理**

- 前置：A3-01、A0-03。
- 需求索引：R33、R34、R35、R50，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：需设计复核。
- 必读：A0-03、03 模型网关；src-tauri/src/db/ai_connections.rs、src-tauri/src/services/credentials.rs、src-tauri/src/services/ai_rate_limit.rs。
- 允许范围：模型网关/流式 Adapter、Agent 用途绑定与 normalize/追加迁移、src/api/connections.ts；保留原 AI 管线。

1. 实现核实过的请求路线、凭据注入、连接版本、限流/预算和取消背压；共享既有连接额度。
2. 增加独立 Agent 用途，不把现有打标服务静默设为助手默认；限定已验证 provider/视觉能力。
3. 将失败、外发范围和连接选择返回 UI；已批准任务服务固定，失败不自动更换连接。
4. 把A0的环境/代理测试迁到真实网关，覆盖SDK辅助请求、哨兵配置、不可达代理、流式中断与取消；SDK升级时重测工具白名单、事件映射和reload。

**验收与交付：** 普通及全部辅助请求覆盖表在生产路径通过；日志/前端/Node 无真实密钥；429/流中断/取消/预算触顶真实可解释。

**停下条件：** 任何 SDK 隐式请求绕过网关或使用未批准服务时，不开放对应能力。

## A3-03

**注册受控领域工具并打通自然语言闭环**

- 前置：A3-02、A2-04。
- 需求索引：R03、R21、R26、R48、R49、R58，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：需设计复核。
- 必读：03 工具契约、06；src-tauri/src/commands/super_search_cmd.rs、src-tauri/src/services/super_search_ai.rs、现行 search-plan-v3。
- 允许范围：Pi 工具 Adapter、搜索/导入/打标计划映射及评估 fixture；不另写 SQL 搜索或 importer。

1. 从 A1 契约注册明确工具名单，转译调用身份、selectionRef/planId/operationId，不向模型暴露批准接口。
2. 先用可控模型完成搜索→预览→准备→等待 GUI 批准→提交→查结果，再接已验证真实模型。
3. 覆盖模糊范围、截断选择、非法参数、恶意文件名/标签指令和重复工具调用；记录后端真实结果。
4. 复用A0-04的E01–E08及A1-01 schema接生产工具；未实现能力保留显式待验证，不能拿PoC通过替代生产证据，至A4-08完成全工具覆盖。

**验收与交付：** 一句导入并生成建议可通过真实领域链路完成；无批准只得到待审计划；prompt 注入不能执行 shell/SQL/扩权。

**停下条件：** 模型文字说成功但无宿主收据，或靠模型自报用户同意继续时不通过。

## A3-04

**实现聊天与历史生命周期**

- 前置：A3-03、A1-06。
- 需求索引：R10、R11、R12、R24、R28、R29、R30，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：普通复核。
- 必读：03 会话恢复、02；src/App.tsx、src/api/client.ts、A1-06 索引/草稿契约。
- 允许范围：拟建助手页面、agent API/store、消息/计划/任务卡及必要宿主索引接入；所有 invoke 经过 src/api。

1. 实现会话打开、新建、最近恢复、发送流、停止回答、搜索/改名/归档/恢复/删除；显示明确模型和附件。
2. 消息增量按实例/run/sequence 去重，最终 snapshot 校准；同一任务卡更新，重要异常单列。
3. 恢复会话读取真实 operation 快照；草稿独立，删除先处理活动任务，取消任务与停止回答分开。

**验收与交付：** 双会话/迟到流/断线/重开/归档删除的行为测试通过；已完成结果不重复写；无活动时新会话空白。

**停下条件：** 持久业务状态留在 React 或把两会话附件合并时返回状态设计修复。

**实现助手右侧导入与标签审核工作台**

- 前置：A3-06、A2-05。
- 需求索引：R13、R14、R18、R19、R22、R27，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：普通复核。
- 必读：src/components/import/PendingList.tsx、src/components/import/RenameBuilder.tsx、src/components/ai/Workbench.tsx、src/components/ai/Filmstrip.tsx、src/pages/AiTaggingPage.tsx。
- 允许范围：右侧工作台组合、共享入库/审核组件/hooks、准确任务绑定及组件测试；不复制领域状态。

1. 默认预览，支持列表/单图；工作台按当前草稿/任务显示并可加宽，必要时收左历史而保留聊天。
2. 附件先留附件，明确导入后展示完整设置/异常/确认/进度；同任务在独立入库页和右侧同步。
3. 复用标签建议切图、编辑、批量确认与打开独立打标页；正式确认由可信 API，防旧建议覆盖新编辑。
4. 从已受理导入 operation/step 接入 `aiPrepareImportBatch`，只按逐项成功收据准备打标范围；重复映射必须由用户明确勾选纳入，禁止从数量或目录推断对象。打标仍走 A2-04 的可信批准和用户显式 GUI start，未启动时不联网；同一导入任务的收据与状态在两处保持一致。

**验收与交付：** 没有 AI 也能右侧导入；两处不重复提交/确认；后台其他对话不抢右栏；不支持文件明细不因窄布局丢失。导入转打标只用成功收据，重复映射需明确选择，且批准 submit 后仍须用户显式启动。

**停下条件：** 只嵌进度条而丢失目标/改名/异常审核，或组件直接 invoke 时修正。

## A3-08

**实现显式交接及素材库结果视图**

- 前置：A3-07。
- 需求索引：R23、R24、R31、R58，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：普通复核。
- 必读：src/pages/LibraryPage.tsx、src/stores/selectionStore.ts、src/stores/libraryStore.ts、src/pages/ImportPage.tsx；现行搜索契约。
- 允许范围：交给助手入口、集合引用/结果路由、素材库临时视图与返回交互。

1. 从素材库或入库页明确交接，展示对象/设置；已运行任务携带引用而不重新提交。
2. 助手结果先在右侧预览，按钮打开素材库的本次结果视图，可退出回正常浏览，不创建分库。
3. 固定交接时集合，处理全选截断、后续筛选改变、原素材被修改/删除和多会话返回。

**验收与交付：** 交接不扩大到全库；用户后来改选择不改旧计划；结果数量和搜索协议一致；离开/返回保留正确上下文。

**停下条件：** 前端只拿当前页 ID 却标为全部结果，或进入结果视图修改真实目录时不通过。
