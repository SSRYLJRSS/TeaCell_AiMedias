# A1：共享契约、授权、数据与任务基础

本文件为静态任务卡。先读 [执行总入口](../11-execution-guide.md) 与 [任务索引](README.md)。每次只读并执行分配的一个 ID；代码范围均相对于仓库根。新增名称在 [12](../12-implementation-contracts.md) 明确为拟建。所有卡同批包含必要定向测试/权威文档，门禁和交接执行 [14](../14-review-and-handoff.md)，未列出不代表可以省略。

## A1-01

**冻结跨入口能力、错误和数据契约**

- 前置：A0-02、A0-04、A0-05、A0-06、A0-07；[A0-03](A0.md#a0-03) 的已验证 mock Adapter 选择和非外发设计结论可用。A0-03 的真实 provider、凭据注入及代理/TUN 矩阵仍阻断 A3-02，不阻断本卡。
- 需求索引：R03、R48、R58，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：需设计复核。
- 必读：12 全文、06；docs/contracts/ 现行搜索/分面协议、src/api/client.ts、src-tauri/src/error.rs。
- 允许范围：docs/contracts/ 与对应 Rust/TS 类型和契约测试；只为真实 2.0 调用创建必要声明。

1. 固定术语、字段、版本、能力清单和可见主体；区分 query/prepare/submit/get/cancel、可信审批与 UI 展示。
2. 为输入类型、错误码、输入/输出限制和恢复语义建立一处权威契约，Rust/TS/工具 schema 从同一事实对齐。
3. 定义不支持平台、无授权、计划过期、范围改变、冲突、结果未知的可观察结果；写跨序列化的成功/失败样例。
4. 固化A0-04初始评估集的case schema与正式契约映射，保留case身份和禁止副作用断言；协议变更须明确版本迁移，不能改弱断言让新实现过关。

**验收与交付：** 每个首发能力有类型和正负样例；非法/多余身份字段不能产生权限；现有搜索/分面协议未被另起一套替代。

**停下条件：** 不能靠 Record<string, any>、通用 execute 或任意 SQL/shell 补缺失契约；回设计任务明确能力。

## A1-02

**落实总仓身份与保护性结构迁移**

- 前置：A1-01。
- 需求索引：R37、R39、R40、R52，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：需设计复核。
- 必读：A0-05 结论；src-tauri/src/db/migrations.rs、src-tauri/src/db/schema_features.rs、src-tauri/src/db/assets.rs、src-tauri/src/db/settings.rs、src-tauri/src/lib.rs。
- 允许范围：拟建 libraries 数据 Module、相关追加迁移、资产定位/设置/启动保护及临时 DB 测试。

1. 按冻结方案追加身份/定位/托管核验与待处理映射，不修改旧迁移；保留既有资产 ID 和关系。
2. 启动先加载保护状态，分类未核验项和总仓健康；到期清理在保护初始化前不能执行。
3. 接入当前根目录查询和普通素材范围，禁止直接更改 root 造成半切换；结构更新后分批核验，不用全库 IO 锁住启动。

**验收与交付：** 新/旧库、重复执行、半结构迁移和根失联测试通过；库外/未知项不被普通列表或自动清理使用，原元数据仍可恢复。

**停下条件：** 无法区分失联与库外，或迁移要求删除旧数据时停止；不能自动清空后重建数据库。

## A1-03

**实现目录授权与受控资源句柄**

- 前置：A1-02。
- 需求索引：R36、R37、R48、R49，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：需设计复核。
- 必读：06 §2/3/7；src-tauri/src/commands/assets_cmd.rs、src-tauri/src/services/imaging.rs、src/api/import.ts。
- 允许范围：拟建 authorization/managed_library 解析 Module、API 类型、授权持久记录和测试；不开放通用文件读取。

1. 由真实 GUI/MCP/Pi Adapter 构造主体，可信选择器授予目录用途和范围；实现本次及记住授权、撤销世代。
2. 实现资产/目录句柄的解析、分页和路径/链接核验，读取与写入/外发分开判断。
3. 对错误主体、跨会话、伪造/过期句柄、根切换、撤权、链接逃逸编写负测；关键 IO 前复核文件身份。

**验收与交付：** 授予本次目录不等于全盘/网络权限；撤销后新读取和可停步骤失败；旧句柄在库世代变更后失效，日志不泄密。

**停下条件：** 任何检查只在 UI 或仅靠字符串前缀时不能通过；不以同账户 sidecar 名字声称 OS 沙箱。

## A1-04

**实现准备计划与原子批准消费**

- 前置：A1-03。
- 需求索引：R26、R43、R44、R51，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：需设计复核。
- 必读：06 §4/5、12 §3；src-tauri/src/state.rs 与 A1-01 契约。
- 允许范围：拟建计划/批准持久 Module、可信确认 API、领域 submit 接口及事务竞争测试。

1. prepare 保存确切输入/目标/模型/限制与 hash，返回 planId；等待审核时不创建执行 operation、不持锁。
2. 可信 UI 对具体计划批准；submit 在短事务核验/消费批准并登记操作及幂等键。
3. 实现同键同计划返回原操作、同键异计划冲突；清空批准与普通整理批准隔离，输入和配置变化返回需复核。

**验收与交付：** 两个并发 submit 只受理一次；approved:true/模型自然语言不能批准；过期/换库/换服务/新范围不能消费旧批准。

**停下条件：** 消费批准与建立操作仍分两次无保护写入时停止，不让后续任务绕开。

## A1-05

**实现可恢复操作队列与逐项收据**

- 前置：A1-04。
- 需求索引：R25、R28、R29、R30、R51、R52，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：需设计复核。
- 必读：A0-04、06 §5/6；src-tauri/src/state.rs、src-tauri/src/db/ai.rs、src-tauri/src/db/export.rs。
- 允许范围：拟建 operations 执行/查询/事件 Module、db 收据、取消和任务关联；必要时接入现有任务注册表。

1. 受理后排队，以固定 operation/step/item 身份派发；保留子域实际执行状态所有权，子任务创建和关联幂等。
2. 实现准确任务取消、进度 revision/snapshot、等待人工阶段释放资源；只读和聊天不被长任务占满。
3. 启动核实文件/DB/子任务收据，呈现恢复摘要；用户继续前不推进副作用，不能判定的效果保留未知。

**验收与交付：** 排队/执行/等待/取消竞争/部分失败/断线重查/重启场景通过；不取消另一会话任务；无重复 AI 批次。

**停下条件：** 只保存 processed 数量、只依赖 event 或把未知当失败重试时不通过。

## A1-06

**建立会话索引与持久工作台草稿**

- 前置：A1-05。
- 需求索引：R10、R11、R12、R18、R23、R24，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：普通复核。
- 必读：02 会话与双工作台、03 §8；src/stores/taskStore.ts、src/pages/ImportPage.tsx、src/stores/aiStore.ts。
- 允许范围：宿主会话元数据/草稿记录及前端 API/store；Pi transcript 保持唯一上下文源。

1. 固定 conversation/draft/plan/operation/batch 关联；手动任务允许无会话，显式交接才绑定。
2. 提供按身份读取/保存草稿、历史排序/搜索投影、改名/归档/删除操作；删除先处理未结束任务，不删素材或必要收据。
3. 重开和切页根据稳定 ID 重建投影；草稿字段校验、附件可访问性和缺失文件明示，不默默重新授权。

**验收与交付：** 两个会话交替编辑不串清单；同一任务两视图一致；页面卸载后草稿保留；记录删除不级联删除素材。

**停下条件：** 出现第二套可独立修改的 transcript/业务进度，或靠最新全局任务 ID 关联时先修数据归属。
