# A4：文件生命周期、迁仓与个人常用流程

本文件为静态任务卡。先读 [执行总入口](../11-execution-guide.md) 与 [任务索引](README.md)。每次只读并执行分配的一个 ID；代码范围均相对于仓库根。新增名称在 [12](../12-implementation-contracts.md) 明确为拟建。所有卡同批包含必要定向测试/权威文档，门禁和交接执行 [14](../14-review-and-handoff.md)，未列出不代表可以省略。

## A4-01

**导出统一为复制，并关闭所有库外移动入口**

- 前置：A3-09。
- 需求索引：R38、R51，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：需设计复核。
- 必读：12 的文件效果表；06 的管理边界；src-tauri/src/services/export_local.rs、src-tauri/src/db/export.rs、src/api/export.ts 及其调用页面。
- 允许范围：现有导出服务、命令/API、导出 UI、Operations 适配及对应测试；不用重写整个素材库。

1. 先枚举旧参数、前端入口和后台调用方，定义旧请求 move=true 指向库外时的明确错误；不能只隐藏界面按钮。
2. 把导出接入已批准的任务和收据。目标目录许可只允许本次复制，重名处理、空间不足、部分成功和取消按逐文件结果处理；库内原记录与原文件保留。
3. 在助手计划和手动导出界面明确写‘复制导出’，完成摘要提供目标位置和失败项；只有已落盘且核验成功才记复制成功。

**验收与交付：** 临时总仓导出到临时外部目录，原件/标签/原路径不变；旧调用库外移动被后端拒绝；目标已存在、权限拒绝、中途取消都返回真实分项结果，重试不静默覆盖。

**停下条件：** 业务调用仍可触发库外移动，或需要自行决定重名覆盖策略而前置契约没有定义时停止。

## A4-02

**总仓内分库移动与结果对账**

- 前置：A4-01。
- 需求索引：R38、R51，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：需设计复核。
- 必读：12 的身份与文件效果约定；src-tauri/src/db/assets.rs、现有分库/导出调用链与 A4-01 的工具注册。
- 允许范围：内部移动服务、必要数据库方法、Operations 工具、手动移动界面及定向测试。

1. 按资源 ID 解析源、目标分库，拒绝库外、未知归属、符号链接/目录联接逃逸及总仓代次过期；计划冻结待移动集合和目标。
2. 在操作日志约束下实施文件移动与数据库路径更新；处理目标重名、目标被占用、源缺失以及文件已动但事务未提交的恢复，禁止假装事务能回滚文件系统。
3. 完成后刷新目录分面、当前结果视图和选中项；部分失败明确保留未移动项，不把整批都计成功。

**验收与交付：** 同总仓内移动后仍是同一个素材 ID，标签/评分/历史不丢；注入中断后能对账，不生成双份活跃记录；手动/Agent 入口拒绝同一越界输入。

**停下条件：** 移动恢复无法判定唯一真实位置、总仓身份不符，或设计需要让模型决定覆盖/清理哪份文件时停止。

## A4-03

**统一移入回收站和恢复行为**

- 前置：A4-02。
- 需求索引：R42、R45、R51，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：需设计复核。
- 必读：02 的删除与恢复产品决定；06 的所有权约束；src-tauri/src/db/assets.rs、回收站现有 UI 和命令、A1 授权规则。
- 允许范围：回收站服务/数据库方法、Agent 工具、现有手动界面及必要 API/测试。

1. 复用现有软删除语义，计划显示具体素材与预计清理时间；检查操作对象仍属于当前总仓。保留现行手动永久删除入口的独立确认，不把该能力暴露成 Agent 任意永久删除工具。
2. 恢复路径同样校验文件实际存在和归属；文件缺失时报告可修复异常，不只把 deleted_at 清空就宣称已恢复。
3. 维护原素材 ID、标签、分库等信息；UI 和收据准确区分已移入、已恢复、失败、已被其他任务处理。

**验收与交付：** 助手只能准备软删除计划；未确认不改数据；恢复保留原元数据；缺失文件、重复请求、总仓离线不会造成静默丢记录。

**停下条件：** 发现旧永久删除路径可绕过所有权核验，或软删除与恢复需要修改现行30天规则时停止并定位冲突。

## A4-04

**独立清空回收站审批与受控到期清理**

- 前置：A4-03。
- 需求索引：R43、R44、R45、R48、R51，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：需设计复核。
- 必读：02/06 的独立清空、30天清理规则；12 的固定快照及文件删除顺序；src-tauri/src/lib.rs 中启动清理路径、回收站服务。
- 允许范围：独立清空工具/审批 UI、自动清理入口、统一删除服务、审计和故障测试；不得扩展 Agent 任意永久删除能力。

1. 清空计划只快照当前可安全处理的回收站项，记录素材版本、总仓代次和 N；只有可信界面的‘永久清空这 N 项’才产生该类审批，普通整段计划确认不能替代。
2. 自动到期清理使用受限系统维护身份与同一删除服务；30天按规范时间字段计算，库外/未知/离线项只报告。任务执行前逐项重新校验，后来进入回收站的项不能被旧确认包含。
3. 逐文件记录删除效果；删文件失败保留数据库记录；文件已删而数据库提交前崩溃，通过持久日志区分真实执行和不明缺失。报告成功/跳过/失败，不对不明项自动扩大范围。

**验收与交付：** 固定 N 后新增一项仍保留；重放审批、Agent伪造确认、过期代次全部拒绝；权限拒绝/磁盘离线不删记录；到期时间边界和中断重启测试真实通过。

**停下条件：** 无法证明文件归属，或现有启动自动清理在迁移/恢复之前仍会运行时，不得启用永久清理。

## A4-05

**总仓迁移与重新定位的可恢复引擎**

- 前置：A4-04、A0-05。
- 需求索引：R37、R40、R41、R51、R55，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：需设计复核。
- 必读：12 的迁仓协议；A0-05/A1-02 固化结果；src-tauri/src/db/settings.rs、src-tauri/src/services/backup_restore.rs 和根路径调用方。
- 允许范围：managed_library 服务、维护任务/日志、设置切换入口、必要数据库迁移与测试；不改图库功能。

1. 实现两条明确命令：软件迁移整个总仓；验证已手动搬好的总仓并重新定位。进入维护状态前检查/收敛在途任务；维护期间停止写入与自动清理，读和旧会话显示维护说明。
2. 迁移按日志执行预检、目标准备、复制和校验、统一路径/根代次切换、可恢复收尾。源目录处置遵循 A0-05 已定协议，不在核验前删除来源；重新定位必须核验身份/清单，拒绝把任意空文件夹当原库。
3. 把‘已切换但源清理未完成’等阶段真实展示为可恢复状态；凭据/旧审批/旧路径句柄不能跨代次继续用。备份恢复同样更新授权代次，避免恢复数据库后旧许可复活。

**验收与交付：** 在每个持久阶段注入崩溃并恢复；容量不足、目标嵌套自身、目录联接、缺文件、错误库身份全部安全中止；成功后素材 ID/标签/任务引用一致且只存在一个当前总仓。

**停下条件：** 维护锁覆盖不了全部写入口、根身份校验不足或无安全回退/继续路径时停止，不自动清理源目录。

## A4-06

**交付迁仓向导和旧库外记录治理界面**

- 前置：A4-05、A2-03。
- 需求索引：R39、R40、R41，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：普通复核。
- 必读：02 的两类迁仓与旧库外记录决定；12 的迁仓交互；src/pages/SettingsPage.tsx、src/api/platform.ts 和 A4-05 服务。
- 允许范围：设置下向导、总仓离线提示、旧数据待处理列表及其 API/hooks/UI测试；复用引擎。

1. 入口明确区分两种操作，展示当前位置、目标、文件数量/容量估计、任务影响和可恢复阶段；先检查后允许切换，不用文本框改路径直接提交。
2. 旧库外记录逐项/批量提供复制回总仓、解除关联；复制回归原素材身份，解除关联保留外部原文件。为同哈希不同元数据按前置协议展示合并/保留结果，禁止自己猜。
3. 离线或归属不明时显示可操作提示；向导成功和部分失败有明确下一步，关闭窗口/重启后恢复原任务摘要，不能新建重复迁移。

**验收与交付：** 以新手流程手测两种向导、错选空目录、磁盘拔出和部分失败；正常回库保留原标签评分；界面与后端收据一致，确认前不切根。

**停下条件：** UI 所需的覆盖、冲突或源目录清理选择没有已经评审的后端契约时停止。

## A4-07

**个人常用流程的保存、编辑和版本管理**

- 前置：A4-06、A0-07。
- 需求索引：R46、R47，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：需设计复核。
- 必读：02 的个人常用流程；03 对受控 Pi 技能的说明；12 和 A0-07 固化格式；会话与设置相关模块。
- 允许范围：受控流程存储/校验模块、流程管理 UI、会话‘保存为常用流程’入口和测试；无插件商店。

1. 从已理解的业务步骤生成待保存草稿，用户可命名和修改分库、打标要求等参数；保存的是允许步骤与参数定义，不是执行审批、原路径凭证或完整历史密钥。
2. 定义并执行版本、必填参数、允许能力与格式校验；编辑产生可识别的新版本，删除/改名不改已经在运行任务使用的快照。默认个人本地范围，禁止自动加载来源不明脚本。
3. 管理入口支持查找、编辑、再次使用；保存前告知需要的能力及运行时仍需选择的输入，无法合法表达的历史操作说明原因而非偷偷生成脚本。

**验收与交付：** 命名/编辑/重启持久化正常；非法动作/脚本/密钥字段拒绝；编辑不篡改在途计划，旧版本引用有可解释行为。

**停下条件：** 实现需要开放任意 JS/shell、自动发现第三方技能或默认永久授予目录权限时停止。

## A4-08

**个人流程每次实例化为新计划并走统一审批**

- 前置：A4-07。
- 需求索引：R46、R47、R26、R43、R49，含义见 [13](../13-requirements-traceability.md)。
- 复核级别：需设计复核。
- 必读：A4-07 格式与版本契约；06 授权；12 对流程实例化和模型边界的规定。
- 允许范围：流程调用适配器、Pi 受控技能入口、计划 UI、Operations 接入及测试。

1. 调用时填写本次输入与参数，重新解析素材/目录/目标分库，生成新的 selection/plan/权限需求；对当前资源核验，不重放旧收据和审批。
2. 步骤进入同一 Operations 队列及模型网关。允许预览修改后再确认；涉及清空回收站仍单独审批，技能描述只能当建议不能提升权限。
3. 服务不存在、输入目录失效、能力版本不兼容时明确阻止并指向可修复入口；完成后在原会话关联本次独立运行结果。
4. 在完整工具集上建立约30–50条中文评估用例，覆盖含糊范围、纠错、重复调用、取消、越权和提示注入；保存预期业务断言、实际文件/DB结果及模型/服务版本。假服务先验证确定性，真实评估使用已批准预算，不只给模型回答打分。

**验收与交付：** 同一流程两次调用产生独立计划；撤销目录许可后重新使用需重授权；恶意名称/描述不能插入未允许工具；保留版本与本次参数可核查。

**停下条件：** 任何流程能绕过新审批、跨任务复用资源句柄或直接调用内部数据库时停止。
