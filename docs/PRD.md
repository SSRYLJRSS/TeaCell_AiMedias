## 1. 产品定义

### 1.1 一句话定位

为个人创作者提供一个本地优先、批量高效、可解释的图片/视频素材库，让素材“进得来、找得到、打得快、拿得走”。

### 1.2 目标用户

- 摄影师、设计师和自媒体创作者。
- 主要管理数千到数万张本地图片、视频和 RAW 文件。
- 需要中文搜索、标签治理、批量 AI 辅助和本地数据安全。

### 1.3 设计原则

1. **本地优先**：素材库、标签和索引默认保存在本机。
2. **人机协作**：AI 只生成建议，用户确认后才写入正式标签。
3. **任务可控**：长任务显示真实阶段和进度，可取消，可恢复，不静默截断。
4. **结果可解释**：搜索、失败、删除和 AI 降级必须让用户知道发生了什么。
5. **数据安全**：删除、移动、恢复和备份均有明确边界，禁止假装成功。
6. **界面克制**：内容优先，减少无关入口、重复信息和装饰性 UI。

## 2. 信息架构

### 2.1 主导航

底栏主入口固定为：

- 入库
- 素材库
- 打标

设置页从素材库进入。超级搜索可通过双击“素材库”进入，悬停或键盘聚焦时显示明确提示。

### 2.2 核心页面

| 页面 | 职责 |
|---|---|
| 入库页 | 选择、暂存、检查、改名并托管导入素材 |
| 素材库 | 浏览、筛选、搜索、批量操作、查看详情与回收站 |
| 超级搜索 | 使用必须、优先、排除、元数据和 AI 条件组合检索 |
| 打标页 | 查看批次、运行 AI、人工确认、编辑标签和撤销批次 |
| 设置页 | AI 连接、本地模型、入库与库位置、外观、数据与缓存、备份恢复 |
| 查看器 | 全屏浏览图片/视频、切换素材、评分、收藏、标签和元数据 |

## 4. 非功能需求

### 4.1 性能

- 3 万素材网格滚动无明显卡顿和白块。
- 普通搜索目标 ≤500ms，内部体感目标 <300ms。
- JPG 320px 缩略图目标 ≤5ms，RW2 320px 目标 ≤100ms。
- 高清 RAW 解码必须异步、限流并放在数据库锁外。
- 数据库锁内禁止网络、解码和大文件 IO。

### 4.2 稳定性

- 迁移必须可重入、可恢复，已发布版本不得回改。
- 崩溃或重启后，遗留 AI 批次不得永久停在 processing。
- 备份恢复必须拒绝与运行中的导入、导出或打标冲突。
- 失败写入不得伪装成功。

### 4.3 安全与隐私

- 本地素材和索引默认不上传。
- 云端 AI 只发送用户明确触发处理的素材预览。
- API Key、token 等凭据进入系统凭据库。
- 路径操作必须防止目录穿越；SQL 必须参数绑定。

### 4.4 可用性

- 1366px 和 1920px 宽度无内容重叠。
- 所有图标按钮有可访问名称或 tooltip。
- 选中、错误、禁用状态不能只依赖颜色。
- 关键操作可用键盘完成。

## 5. 当前不做的范围

| 方向 | 决策 |
|---|---|
| 百度网盘/夸克网盘导出 | 暂缓，外部接口或资质条件未满足 |
| 目录自动监控 | 暂缓，先保证显式入库链路稳定 |
| 音频素材 | 远期 |
| 多设备同步和账号体系 | 远期，与纯单机本地优先定位存在冲突 |
| 跨设备素材库迁移 / 自动同步（`.btlib` 迁移包、迁移导出/导入/激活） | 本版本明确不提供；仅保留数据库备份/恢复。此处「不含跨设备迁移」不影响下文的 SQLite schema 版本迁移与设置 normalize 迁移 |
| CLIP 语义向量搜索 | 远期，需模型、存储和迁移方案完整设计 |
| AVIF/JPEG XL | 在解码依赖、体积和分发风险明确后再评估 |

## 6. 发布验收

发布前必须满足：

1. `scripts/smoke.ps1` 完整通过。
2. 自动化质量门禁全部通过。
3. 使用真实素材完成 [QA_PLAYBOOK.md](QA_PLAYBOOK.md) 中 P0 场景。
4. 超级搜索 relevance、mustNot、位置权重和 hydrate 行为有真实数据证据。
5. 导入、查看器、AI 打标、导出、删除恢复、备份恢复主链路无 P0/P1 未解决缺陷。
6. 当前版本的数据迁移、备份和恢复路径已验证。

## 7. 产品不变量

1. 素材文件不得因 UI 假成功而丢失。
2. AI 不得绕过人工确认直接改写正式标签。
3. 搜索条件只有一个执行计划，不允许列表、总数、全选和诊断各走一套逻辑。
4. 分面 key 是机器协议，展示名不是协议。
5. 任何“删除”和“移动”都必须能解释最终文件和数据库状态。
6. 任何降级结果都必须让用户看见原因，不能静默变成另一条查询或空结果。
7. 用户已保存的搜索计划、标签、评分和回收站状态必须跨重启保持。
